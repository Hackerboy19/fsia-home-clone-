✦ Complete Technical Blueprint

Developer API & Database Architecture Specifications

This document outlines the exact database tables, REST API contracts, and media standards required to construct the production admin panel.

1. PostgreSQL / SQL Database Schema

Execute these DDL commands in your PostgreSQL, Supabase, Neon, or MySQL database to instantiate all tables: 

-- 1. HERO SLIDER TABLE
CREATE TABLE hero_slides (
    id SERIAL PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    subtitle VARCHAR(255),
    image_url TEXT NOT NULL,
    cta_url TEXT DEFAULT 'https://www.fsia.in/quickapply',
    cta_text VARCHAR(100) DEFAULT 'Explore Details',
    display_order INT DEFAULT 1,
    is_active BOOLEAN DEFAULT TRUE,
    aspect_ratio VARCHAR(20) DEFAULT '3:2', -- 1200x800 px
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 2. CALENDAR EVENTS & AUDITIONS TABLE
CREATE TABLE calendar_events (
    id VARCHAR(100) PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    category VARCHAR(100) NOT NULL,
    event_type VARCHAR(50) NOT NULL, -- 'pageant', 'award', 'audition', 'ceremony', 'workshop'
    event_date DATE NOT NULL,
    time_ist VARCHAR(50) NOT NULL,
    venue VARCHAR(255) NOT NULL,
    city VARCHAR(100) NOT NULL,
    description TEXT,
    eligibility TEXT,
    highlights JSONB DEFAULT '[]',
    cta_text VARCHAR(100) DEFAULT 'Apply for Audition',
    cta_url TEXT NOT NULL,
    image_url TEXT,
    status VARCHAR(50) DEFAULT 'active',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 3. WINNER SUCCESS STORIES & REELS TABLE
CREATE TABLE success_stories (
    id VARCHAR(100) PRIMARY KEY,
    winner_name VARCHAR(255) NOT NULL,
    title VARCHAR(255) NOT NULL,
    category VARCHAR(100) NOT NULL,
    location VARCHAR(100) NOT NULL,
    season VARCHAR(20) NOT NULL,
    image_url TEXT,
    has_missing_image BOOLEAN DEFAULT FALSE,
    quote TEXT NOT NULL,
    story TEXT NOT NULL,
    advice TEXT,
    profile_url TEXT,
    video_sim_duration INT DEFAULT 15,
    slides JSONB DEFAULT '[]',
    ai_generated BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- 4. AUDITION APPLICATIONS & LEADS TABLE
CREATE TABLE audition_applications (
    id SERIAL PRIMARY KEY,
    application_code VARCHAR(50) UNIQUE NOT NULL,
    full_name VARCHAR(255) NOT NULL,
    email VARCHAR(255) NOT NULL,
    phone VARCHAR(50) NOT NULL,
    category VARCHAR(100) NOT NULL,
    city VARCHAR(100) NOT NULL,
    state VARCHAR(100) NOT NULL,
    status VARCHAR(50) DEFAULT 'pending', -- 'pending', 'verified', 'shortlisted', 'rejected'
    notes TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

2. Standard REST API Routes to Implement

Method Endpoint Purpose Auth Required
GET /api/sliders Returns all active hero slides in display_order No (Public)
POST /api/admin/sliders Creates a new banner slide with image URL Yes (Bearer JWT)
PUT /api/admin/sliders/:id Updates slide title, link, order, or image Yes (Bearer JWT)
DELETE /api/admin/sliders/:id Deletes or deactivates slide Yes (Bearer JWT)
GET /api/events Returns upcoming calendar dates and auditions No (Public)
POST /api/generate-testimonial Invokes Gemini AI to synthesize missing winner quotes Internal Server

3. Media Assets & Sizing Specs

  • Hero Slider: 1200 × 800 px (3:2 ratio) or 1920 × 1080 px (16:9). Maximum weight: 450 KB. Formats: WebP, progressive JPEG, PNG.
  • Winner Reels: 1080 × 1920 px (9:16 vertical ratio). Maximum weight: 600 KB.
  • City Audition Badges: 400 × 400 px (1:1 square).
  • Media Storage: AWS S3, Cloudflare R2, Google Cloud Storage, or Firebase Storage with public CDN caching enabled.
